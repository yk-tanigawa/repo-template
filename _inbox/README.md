# _inbox

Use this folder as a short-lived local intake area for unsorted files.

Actual files placed here are ignored because they may be sensitive, large, generated, prior versions, private correspondence, or raw data. Triage them promptly using [docs/inbox-triage.md](../docs/inbox-triage.md), then move each file either into tracked repository sources or into the external `_data/` tree.

Do not force-add files from this folder.
