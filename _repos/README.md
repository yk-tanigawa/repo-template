# Related Repositories

Use this directory for ignored local symlinks to related repository clones.

Keep machine-specific clone paths in `.env.local`, document the variables in `.env.local.example`, and list configured links in `PROJECT_RELATED_REPOS`. Run `make setup` to create or refresh the local symlinks.

Only this README is tracked. Do not commit related repository symlinks, clones, private files, or generated outputs under `_repos/`.
